# Fundación Forma — sitio web

Sitio institucional oficial de Fundación Forma, preparado para publicarse con GitHub Pages en `fundacionforma.org`.

## Publicación

El sitio es estático y no requiere procesos de compilación. GitHub Pages debe publicarse desde la rama `main` y la carpeta raíz `/`.
